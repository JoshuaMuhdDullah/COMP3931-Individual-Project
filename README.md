# Fluid Simulation Using Taichi

This project contains Taichi implementations of three SPH fluid solvers:

- **DFSPH**
- **IISPH**
- **WCSPH**

## Requirements

Install the required Python packages:

```bash
pip install taichi numpy
```

# How to run

Run each solver from the project directory:

python wcsph.py
python iisph.py
python dfsph.py
